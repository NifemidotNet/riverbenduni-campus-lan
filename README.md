##Scenario: University campus with 2 buildings: Building A(HQ), Building B(Science & Tech), and a 3-Tier Campus LAN Architecture featuring basic essential LAN configurations including:
- Multiple VLAN setup and configuration
- LAG (etherChannels - LACP)
- STP (rapid-pvst, portfast, bpduguard)
- FHRP (HSRP)
- Dynamic Routing with OSPF (single area)
- NAT Overload/PAT
- remote management via SSH (L2,L3)
- Wireless LAN (Split-MAC central Switching - No FlexConnect)
